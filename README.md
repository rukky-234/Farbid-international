# Farbid International

Source code for the Farbid International corporate website.

## Pages

- Home
- About Us
- Services
- Contact Us

The site includes responsive desktop and mobile navigation, locally stored image assets, contact details, and the complete Farbid International visual design.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Node.js 22.13 or newer is recommended.
